## 快速开始

编写一个新组件的示例只需 **5 步**：

```
① 创建组件      →  src/components/YourComponent/
② 添加配置      →  doc/example.json 中新增条目
③ 编写示例      →  doc/ 下创建 .js 示例文件
④ 补充文档      →  doc/api.md 中添加 API 说明
⑤ 确认导出      →  src/index.js 中导出组件
```

## 目录结构规范

### 标准项目布局

```
项目根目录/
├── src/
│   ├── components/
│   │   ├── ComponentA/
│   │   ├── ComponentB/
│   │   │   ├── Sub1/
│   │   │   ├── Sub2/
│   │   │   └── index.js          # 组件入口，导出所有子组件
│   │   └── ...
│   └── index.js                  # 项目主入口
├── doc/                          # 文档 & 示例（所有组件共用）
│   ├── example.json              # ⭐ 示例配置文件（核心）
│   ├── api.md                    # API 文档
│   ├── summary.md                # 项目简介
│   ├── base.js                   # 基础示例
│   ├── component-a.js            # ComponentA 示例
│   ├── component-b.js            # ComponentB 主示例
│   ├── component-b-sub1.js       # ComponentB → Sub1 示例
│   └── style.scss                # 示例样式（可选）
└── package.json
```

### 示例文件命名规则

| 场景 | 命名方式 | 示例 |
|------|---------|------|
| 单一组件 | 组件名小写短横线 | `component-a.js` |
| 带子组件的父组件 | 组件名小写短横线 | `component-b.js` |
| 子组件 | `父组件-子组件` | `component-b-sub1.js` |

> **核心原则**：所有示例文件统一放在项目根目录的 `doc/` 下，不要在单个组件目录内创建 `doc/` 子目录。

## example.json 配置

所有示例的入口配置集中在 `doc/example.json` 中管理。

### 完整配置结构

```json
{
  "isFull": true,
  "list": [
    {
      "title": "组件显示名称",
      "description": "简短的功能描述",
      "code": "./example-file.js",
      "scope": [
        {
          "name": "_LibName",
          "packageName": "@kne/current-lib_package-suffix",
          "importStatement": "import * as _LibName from \"@your-org/package-name\""
        },
        {
          "packageName": "@kne/current-lib_package-suffix/dist/index.css"
        }
      ]
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `isFull` | boolean | 否 | 是否全屏展示示例，默认 `false` |
| `list` | array | 是 | 示例列表，每项对应一个示例页面 |
| `list[].title` | string | 是 | 示例页面的标题 |
| `list[].description` | string | 是 | 示例的简要描述 |
| `list[].code` | string | 是 | 示例代码文件路径，相对于 `doc/` |
| `list[].scope` | array | 是 | 依赖声明列表 |

### scope 依赖声明

每个 scope 项用于声明示例代码中需要引入的外部依赖。

| 场景 | name | packageName | importStatement |
|------|------|-------------|-----------------|
| 当前开发包 | `_LibName` | `@kne/current-lib_suffix` | `import * as _LibName from "package"` |
| CSS 样式 | — | `@kne/current-lib_suffix/dist/index.css` | — |
| 远程加载器 | `remoteLoader` | `@kne/remote-loader` | — |
| Ant Design | `antd` | `antd` | — |
| React | `React` | — | 无需声明 |

> **关于 `@kne/current-lib_*`**：这是文档系统用来引用「当前正在开发的组件包」的特殊标识。例如 `@kne/info-page` 项目使用 `@kne/current-lib_info-page`，这样系统会自动加载开发中的最新版本，而不是 npm 上的已发布版本。

## 示例代码编写

### 编写原则

1. **充分展示 API**：覆盖所有核心 props、回调函数、不同配置组合，以及边界场景
2. **贴近真实业务**：使用有意义的字段名和数据结构，模拟真实接口返回格式
3. **代码清晰可读**：合理拆分逻辑，添加必要的注释

### 导入方式

```javascript
// 从 scope 声明的变量名导入组件
const { ScrollLoader, FetchScrollLoader } = _ScrollLoader;

// 工具包引用
const { createWithRemoteLoader, getPublicPath } = remoteLoader;

// antd 组件
const { Flex, Switch, Space } = antd;
```

### 模板一：标准示例（需要数据模拟）

适用于需要 `PureGlobal` 提供 mock 数据的场景。

```javascript
const { YourComponent } = _LibName;
const { createWithRemoteLoader, getPublicPath } = remoteLoader;

const BaseExample = createWithRemoteLoader({
  modules: ['components-core:Global@PureGlobal', 'components-core:InfoPage']
})(({ remoteModules }) => {
  const [PureGlobal, InfoPage] = remoteModules;

  return (
    <PureGlobal
      preset={{
        ajax: async api => {
          return { data: { code: 0, data: api.loader() } };
        },
        apis: {
          file: {
            staticUrl: getPublicPath('project-name') || window.PUBLIC_URL,
            getUrl: {
              loader: async ({ params }) => {
                // 模拟数据逻辑
                return 'mock-url';
              }
            }
          }
        }
      }}
    >
      <InfoPage>
        <InfoPage.Part title="示例标题">
          <YourComponent prop="value" />
        </InfoPage.Part>
      </InfoPage>
    </PureGlobal>
  );
});

render(<BaseExample />);
```

### 模板二：简化示例（无远程依赖）

适用于不需要外部数据、纯 UI 展示的组件。

```javascript
const { YourComponent } = _LibName;
const { Flex, Switch } = antd;
const { useState } = React;

const BaseExample = () => {
  const [state, setState] = useState(false);

  return (
    <Flex vertical gap={12}>
      <YourComponent
        prop={state}
        onChange={setState}
      />
    </Flex>
  );
};

render(<BaseExample />);
```

## API 文档编写

API 文档统一放在 `doc/api.md`，使用 Markdown 表格格式。

### 文档模板

```markdown
### 组件名称

简要描述组件的作用和功能。

#### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| propName | `string` | — | 属性的详细说明 |
| callback | `(data) => void` | — | 回调函数的参数和用途 |

#### 子属性（如需要）

若某个属性是对象类型，可单独列表说明：

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| parent.childName | `number` | 10 | 子属性的说明 |
```

### 实际示例

```markdown
### ScrollLoader

基础的滚动加载组件，当底部哨兵元素进入视口时触发加载更多数据的回调函数。

#### 属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| className | `string` | — | 自定义类名 |
| noMore | `boolean` | — | 是否没有更多数据 |
| onLoader | `() => Promise<void>` | — | 加载更多数据的回调 |
| isLoading | `boolean` | — | 是否正在加载中 |
| completeTips | `string` | "已加载全部数据" | 加载完成提示文本 |
| maxFullCount | `number` | 3 | 内容不足滚动时，自动加载的最大次数 |
| useSimpleBar | `boolean` | true | 是否使用 SimpleBar 滚动容器 |
| children | `ReactNode` | — | 子元素（数据列表） |
```

## 数据模拟

在示例中通过 `PureGlobal` 的 `preset` 配置模拟数据环境。

### 基本结构

```javascript
preset: {
  ajax: async api => {
    // 拦截所有请求，返回模拟数据
    return { data: { code: 0, data: api.loader() } };
  },
  apis: {
    file: {
      staticUrl: getPublicPath('project-name') || window.PUBLIC_URL,
      getUrl: {
        loader: async ({ params }) => {
          // 根据 params 返回对应的 mock 数据
          const urlMap = {
            1: '/mock/example.png',
            2: '/mock/example.pdf'
          };
          return new Promise(resolve => {
            setTimeout(() => resolve(urlMap[params.id]), 500);
          });
        }
      }
    }
  }
}
```

### 模拟分页接口

```javascript
loader: ({ data }) => {
  const { currentPage = 1, perPage = 20 } = data;
  return new Promise(resolve => {
    const start = (currentPage - 1) * perPage;
    setTimeout(() => {
      resolve({
        totalCount: 100,
        pageData: Array.from({ length: perPage }, (_, i) => ({
          label: `第 ${start + i + 1} 项`,
          value: start + i + 1
        }))
      });
    }, 500);
  });
}
```

## 附录：变量速查表

### 项目变量映射

根据 `package.json` 中的配置自动推导变量值。

| 变量名 | 来源 | 示例（`@your-org/your-project`） |
|--------|------|----------------------------------|
| `{PACKAGE_NAME}` | `package.json` → `name` | `@your-org/your-project` |
| `{PROJECT_NAME}` | 包名中 `@scope/` 后的部分 | `your-project` |
| `{LIB_NAME}` | 驼峰形式的库名 | `YourProject` |
| `{PACKAGE_NAME_SUFFIX}` | 同 `{PROJECT_NAME}` | `your-project` |

### 替换对照

**example.json 中的 scope 声明**：

```json
// 标准引用
{
  "name": "_YourProject",
  "packageName": "@your-org/your-project",
  "importStatement": "import * as _YourProject from \"@your-org/your-project\""
}

// 引用当前开发包（推荐用于开发阶段）
{
  "name": "_YourProject",
  "packageName": "@kne/current-lib_your-project",
  "importStatement": "import * as _YourProject from \"@your-org/your-project\""
}
```

**示例代码中的使用**：

```javascript
const { YourComponent } = _YourProject;
const { createWithRemoteLoader, getPublicPath } = remoteLoader;

// 配置静态资源路径
staticUrl: getPublicPath('your-project') || window.PUBLIC_URL,
```
